# ExHeadStudio-Marconi

Repository for Ex-Head Studio's Marconi project - Level UP 2025

## About

This is a Unity project repository for the Level UP 2025 initiative by Ex-Head Studio.

## Project Structure

```
├── Assets/              # Unity assets and project files
│   ├── Materials/       # Material files
│   ├── Prefabs/         # Prefab objects
│   ├── Scenes/          # Unity scenes
│   ├── Scripts/         # C# scripts
│   ├── ScriptableObjects/ # ScriptableObject definitions
│   ├── Settings/        # Project settings
│   ├── Textures/        # Texture files
│   └── TextMesh Pro/    # TextMesh Pro assets
├── Packages/            # Unity package dependencies
└── ProjectSettings/     # Unity project configuration

```

## Requirements

- Unity (version specified in ProjectSettings/ProjectVersion.txt)
- Compatible IDE (Visual Studio, Rider, or Visual Studio Code)

## Getting Started

1. Clone this repository
2. Open the project in Unity Hub
3. Let Unity import all assets
4. Open the main scene from Assets/Scenes/

## Development

This project follows Unity development best practices. Please ensure all changes are tested before committing.
